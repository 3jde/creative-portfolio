# 羽众不同

游戏公开地址：https://www.onezgames.com/games/feather-club/

使用 Node.js 22.13 以上版本。执行 `npm install`、`npm run dev` 开发；执行 `npm test` 验证比赛逻辑；执行 `npm run build` 生成 dist-static，将内容复制到网站 games/feather-club 即可发布。

鼠标移动球拍；左键蓄力、松开击球；右键按住近网、松开底线；Esc 暂停。三档难度、男女外观、三种服装、四种配色。先得 11 分获胜。

静态构建无需服务器、ChatGPT 登录或第三方素材服务。全部游戏依赖与页面随站点发布。
