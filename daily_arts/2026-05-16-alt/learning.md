# Daily Art 2026-05-16 Alternative

## Direction

User requested a backup set for 2026-05-16 that starts from static world-famous paintings and turns them into interactive/generative dynamic art, while avoiding repetition from previous daily_art works.

## Sketches

- starry.html: Vincent van Gogh, The Starry Night. Reinterprets brush swirls as gravitational particle currents. Pointer/touch pulls the night sky; space toggles storm intensity.
- wave.html: Katsushika Hokusai, The Great Wave off Kanagawa. Reinterprets ukiyo-e wave contours as responsive tide lines. Dragging creates wave crests and foam.
- mondrian.html: Piet Mondrian, Composition with Red, Blue and Yellow. Reinterprets static neoplastic grid as a rhythmic interactive city. Pointer bends the grid; keys 1/2/3 alter beat speed.

## Anti-Repetition Notes

- Different source artworks: post-impressionist night landscape, ukiyo-e seascape, neoplastic abstraction.
- Different interaction models: gravitational attraction, direct fluid displacement, rhythmic grid reconfiguration.
- Different motion languages: star trails, wave contours, architectural pulses.
- Different visual structures: atmospheric sky, layered horizontal tide, rectilinear composition.
