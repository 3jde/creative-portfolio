# Daily Interactive Art - 2026-05-27

Source references:
- J. M. W. Turner, The Fighting Temeraire / late storm-light seascapes - transformed into a WebGL vortex of light ribbons, rain sparks, and a near-abstract vessel silhouette.
- Eugene Delacroix, Liberty Leading the People - transformed into a symbolic crowd field where bodies rally, scatter, and rebuild around a moving flag.
- Kazimir Malevich, Black Square and Suprematist compositions - transformed into a restrained generative clock of slight imbalance, paper texture, and temporal drift.

Sketches:
- visual.html / visual.js - Visual Impact: Turner-inspired light engine using WebGL depth, chromatic turbulence, orbit camera, and pointer-bent storm lens.
- interactive.html / interactive.js - Novel Interaction: Delacroix-inspired crowd physics; drag to pull figures, press Space for a flare, S to scatter, R to rebuild.
- artistic.html / artistic.js - Artistic Quality: Malevich-inspired minimal composition with quiet motion, click-to-reseed layout, and pointer-controlled balance.

Interactive design learning:
- MANA / Manamana search reference: www.manamana.net positions new-media art around art, design, technology, and cross-industry innovation. The useful pattern today is to treat interaction as the work's conceptual engine, not as a decorative UI layer.
- The TouchDesigner/forum references emphasize projection, light effects, installation formats, and emotional immersion. Today's sketches apply that by making motion systems carry the meaning: storm pressure, civic momentum, and geometric restraint.
- Future creative tasks should keep source artwork, interaction model, and motion language independent so each sketch is a distinct study rather than a palette swap.
