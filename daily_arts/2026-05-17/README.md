# Daily Interactive Art - 2026-05-17

Source references:
- Hieronymus Bosch, The Garden of Earthly Delights - transformed into a rotating WebGL organism of rings, cones, and emblem-like fragments.
- Wassily Kandinsky, abstract composition language - transformed into a touch-driven kinetic score where shapes repel, connect, and ring outward.
- Georges Seurat, A Sunday Afternoon on the Island of La Grande Jatte - transformed into a pointillist landscape whose dots drift with pointer-controlled light.

Sketches:
- visual.html / visual.js - Visual Impact: Bosch-inspired garden engine, luminous 3D rings, symbolic seed forms, pointer camera pressure.
- interactive.html / interactive.js - Novel Interaction: Kandinsky-inspired playable composition, drag/touch pulses push the whole score, double-click resets.
- artistic.html / artistic.js - Artistic Quality: Seurat-inspired pointillist river scene, quiet color drift and brush-light interaction.
