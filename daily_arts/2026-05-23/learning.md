# Interactive Design Learning - 2026-05-23

Search focus: current UI/interactive-design examples and public-domain artwork translation strategies.

Useful signals:
- Strong contemporary interactive design keeps narrative and input tied together: cursor as lens, touch as sound/force, scroll as spatial navigation, and motion as system behavior rather than decoration.
- Dense visual work benefits from an anchor structure. For today, Bosch uses a triptych, Alma Thomas uses a regular mosaic score, and Friedrich uses horizon layers; each gives the motion a readable frame.
- Mobile interaction should stay direct and low-friction. Tap, drag, and pointer proximity are enough when the visual metaphor is clear.
- For future daily sketches, reserve WebGL for depth or spatial ecology. Use 2D canvas when the art is about rhythm, surface, atmosphere, or color fields.
