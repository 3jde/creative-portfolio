## Phone viewing
Open the HTML files in a browser from this folder. Best quick path: serve the workspace locally, then visit the machine LAN URL on the phone.
Example from workspace root: `python3 -m http.server 8080`, then open `/daily_art/2026-05-10/visual.html` etc.

## Learning notes
- 2026 design direction emphasizes imperfect, tactile interfaces over polished static screens.
- Motion should carry meaning: scroll/state transitions, pointer physics, and spatial depth are stronger than decorative animation.
- High-end visual sites are converging on WebGL/WebGPU, procedural materials, modular grids, and story-first immersive scenes.
